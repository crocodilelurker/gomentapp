## This file contains a set of rules for agentic development for all agents working in this folder

# Rules 
1. We are operating in a Test Driven Development so always write unit tests and do not test them do not run preview browsers to test them
2. If any major decisions are taken Store the decisions in ./DECISIONS.md file in short and clear points wise
3. Never write any mock data unless explicitly mentioned to write the mock data
4. Never write any non-truth data in the development, unless explicitly mentioned
5. Always update the README.md whenever necessary
